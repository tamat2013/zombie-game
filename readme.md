# 🧟 Zombie Multiplayer Game

משחק מולטיפלייר מותח בסגנון זומבים עבור React Native, שפותח עם Expo ו-Firebase.

## 📋 תיאור

משחק פעולה מולטיפלייר מרתק שבו שחקנים מתחלקים לזומבים ושורדים. השורדים צריכים להשלים משימות ולהימנע מהדבקה, בעוד הזומבים מנסים להדביק את כל השחקנים. המשחק כולל מערכת שדרוגים, סקינים מיוחדים, יכולות ייחודיות, ועוד תכונות מתקדמות.

- **מצב קלאסי**: שורדים נגד זומבים עם טיימר של 10 דקות
- **טורנירים**: תחרויות מתוזמנות עם פרסים מיוחדים
- **מסלול מכשולים**: אימון ומבחני מיומנות

## 🎮 איך לשחק

### למתחילים

1. **התחברות**: הירשם או התחבר עם אימייל וסיסמה
2. **בחירת סקין**: בחר את הסקין המועדף עליך
3. **בחירת מפה**: בחר מפה או צור מפה משלך
4. **לובי**: המתן לשחקנים נוספים להצטרף
5. **משחק**: שחק כשורד או זומבי ונסה לנצח!

### כשורד

- 🏃 ברח מהזומבים
- ✅ השלם משימות לקבלת XP
- 💊 השתמש ביכולות מיוחדות (רופא, חיפוש, מהירות)
- 🤝 עבוד בשיתוף פעולה עם שחקנים אחרים
- ⏱️ שרוד 10 דקות כדי לנצח

### כזומבי

- 🧟 הדבק שורדים על ידי נגיעה בהם
- 👁️ השתמש בראיית זומבי לאיתור שחקנים
- 💨 השתמש ביכולות להאצה
- 🎯 הפוך את כל השחקנים לזומבים כדי לנצח
